# INSACERMO V5 — Finite Adaptive Sensing Target

Date frozen: 2026-09-12

## Question

Does the frozen actionability kernel still survive when a policy receives observations during execution and branches on the accumulated observation history?

This is the first post-V4 target in which information is acquired *inside* the policy execution rather than supplied only through the initial representation.

## Frozen system

A deterministic finite-horizon adaptive system contains:

- hidden/current world state `S`;
- control action type `U`;
- internal observation type `O`;
- transition `step : S -> U -> S`;
- internal sensor `observe : S -> O`;
- history-dependent policy `pi : List O -> U`.

The generated control at each time is therefore a function of the observations accumulated so far.

## Contract

For a fixed horizon, state-safety predicate and terminal-goal predicate, define `AdaptiveGood(s,pi)` from the closed-loop trajectory generated by `step`, `observe` and `pi`.

The external actionability representation `h : S -> Y` remains separate from the observations that the policy is explicitly allowed to acquire internally.

Adaptive actionability is then the frozen kernel:

`AdaptiveSafeRep := SafeRep AdaptiveGood`.

## Nontrivial target: internal sensor refinement

Suppose `fineObs` refines `coarseObs` through a decoder

`coarseObs(s) = decode(fineObs(s))`.

Every coarse-history policy should have a lifted fine-history policy

`lift(pi)(hf) = pi(map decode hf)`

that reproduces the exact same control sequence and state trajectory.

Therefore a finer internal sensor should never destroy adaptive actionability when the coarse policy capability set is lifted into the fine policy space.

This is distinct from the already verified external-information monotonicity theorem: the new statement concerns information acquired by the capability while it is executing.

## Theorems to test

1. exact final-state simulation under sensor refinement;
2. exact whole-trajectory simulation under sensor refinement;
3. preservation of the adaptive safety/goal contract for every lifted policy;
4. preservation of `SafeRep` after lifting the policy capability set;
5. finite minimal-obstruction/hypergraph characterization for the adaptive contract.

## Guardrail

Internal observations are not free hidden information. The sensor channel is part of the capability contract. Changing the internal sensor changes the policy capability space and must be represented explicitly.

## Scope boundary

This target is deterministic and finite horizon. It is not yet a stochastic-observation POMDP, Bayesian belief-state theorem, unknown-model learning theorem, infinite-horizon result, or continuous-space result.

If this target passes, the next genuine frontier is stochastic hidden-state / observation-history adaptation where the policy acts under distributions over latent worlds and updates information through random observations.
