# INSACERMO V5 — Infinite-Horizon Discounted Bellman Contraction Target

Date frozen: 2026-09-12

## Question

Does the INSACERMO actionability skeleton survive the first genuinely infinite-horizon control extension, where action admissibility is generated by a discounted Bellman fixed point rather than by a finite-horizon recursion?

The frozen architectural skeleton remains:

`Contract -> Actionability / Obstructions -> Planner`

No new runtime layer is introduced.

## Scope of this first infinite-horizon target

This V0 target deliberately works on a **finite closed decision-state graph** `X` with a finite nonempty action type `A`. A node of `X` may represent an exact belief state, an augmented belief state, or a certified finite belief abstraction. The stochastic dynamics on this graph are supplied as a normalized finite transition law.

This is intentionally narrower than the full continuous POMDP belief simplex. It isolates the infinite-horizon/fixed-point issue from measure theory and continuous-state approximation.

## Frozen model

- finite state/node type `X`;
- finite nonempty action type `A`;
- exact rational transition law `P : X -> A -> FiniteLaw X`;
- real stage cost `c : X -> A -> Real`;
- discount `gamma : Real` with `0 <= gamma` and `gamma < 1`;
- value functions `V : X -> Real`.

Define

`Q_V(x,a) = c(x,a) + gamma * sum_x' P(x,a)(x') * V(x')`.

Define the Bellman operator

`T(V)(x) = min_a Q_V(x,a)`.

## Frozen theorem targets

1. Finite-action real minimum exists and is attained.
2. A normalized finite transition law maps a uniform value error `delta` to an expected-value error at most `delta`.
3. For fixed `(x,a)`, Bellman Q-values satisfy the discounted bound

   `|Q_V(x,a) - Q_W(x,a)| <= gamma * delta`

   whenever `|V(y)-W(y)| <= delta` for every node `y`.
4. The Bellman minimum preserves the same uniform bound:

   `|T(V)(x) - T(W)(x)| <= gamma * delta`.
5. Therefore the Bellman operator is a `gamma`-contraction in the finite sup-distance sense.
6. Any two Bellman fixed points are equal when `0 <= gamma < 1`.
7. If a fixed point `Vstar` is supplied/proved, define `InfiniteBellmanGood(x,a)` by exact minimization of `Q_Vstar` and instantiate `SafeRep` with it.
8. Prove capability and information-refinement monotonicity for that infinite-horizon actionability contract.
9. Connect the fixed-point optimal-action contract to the existing sequential INSACERMO planner exactly as in the finite-horizon belief planner.

## Existence target and discipline

A full Banach fixed-point existence theorem is a separate subtarget inside this same research stage. It must not be claimed merely from the contraction inequality.

Two acceptable formal closures are:

- prove existence directly in an appropriate complete finite-dimensional function space; or
- explicitly mark existence as pending while keeping contraction + uniqueness verified.

Do not silently upgrade uniqueness to existence.

## Interpretation target

If contraction and fixed-point actionability pass, then the first infinite-horizon extension has the form

`finite belief/decision graph -> discounted Bellman operator -> fixed-point optimal-action contract -> SafeRep -> planner`.

This would show that the actionability kernel does not depend on a finite control horizon once an admissibility contract is generated by a well-defined discounted stationary value solution.

## Guardrails

This target does NOT yet prove:

- full continuous POMDP belief-space fixed points;
- measurable-state dynamic programming;
- average-cost or undiscounted `gamma = 1` control;
- unknown-model learning;
- Bayesian model uncertainty unless encoded in `X`;
- path-dependent budgets unless included in the decision state;
- approximation error guarantees for a finite belief abstraction;
- historical novelty.

## Falsification boundary

If contraction fails under the frozen hypotheses, the infinite-horizon extension does not inherit the finite-horizon Bellman structure as expected. If fixed-point actionability exists but cannot be routed through the existing planner, the three-layer architecture must be reconsidered rather than patched by adding ad hoc layers.
