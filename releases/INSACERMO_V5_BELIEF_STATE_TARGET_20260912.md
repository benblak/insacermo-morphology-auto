# INSACERMO V5 — Belief-State Sufficiency Target

Date frozen: 2026-09-12

## Question

When a partially observed sequential system is summarized by a belief state, exactly when may the full observation/action history be forgotten without changing actionability?

This is the first post-V4 target aimed at the POMDP frontier. It deliberately separates two questions:

1. whether a belief representation is a sufficient statistic for the decision contract;
2. whether a specific Bayesian/POMDP model actually computes such a sufficient belief correctly.

Only the first question is targeted here.

## Abstract belief machine

Let `History` denote finite action/observation histories, `Belief` a candidate compressed state, and

`beta : History -> Belief`

be the history-to-belief map generated by some update mechanism.

For action/policy type `A`, let

`GoodHistory : History -> A -> Prop`

be the true admissibility contract at history level, and

`GoodBelief : Belief -> A -> Prop`

be a proposed belief-level contract.

## Exact sufficiency condition

The belief is contract-sufficient exactly when admissibility factors through `beta`:

`GoodHistory(h,a) <-> GoodBelief(beta(h),a)`

for every admissible history `h` and candidate action/policy `a`.

This is stronger and more precise than saying that the belief is statistically convenient. It states that no distinction erased by `beta` can change which actions are admissible under the declared contract.

## Main theorem target

For any external representation `r : Belief -> Y`, history-level actionability through `r o beta` should be exactly equivalent to belief-level actionability on the realized belief image:

`SafeRep GoodHistory BH C (r o beta)`

iff

`SafeRep GoodBelief (beta '' BH) C r`.

Thus a sufficient belief state is a lossless quotient for actionability.

## Consequence

If the theorem passes, INSACERMO obtains an exact criterion for when history can be forgotten in a partially observed decision process:

> history compression to belief is valid precisely to the extent that the actionability contract factors through belief.

If factorization fails, two histories with the same candidate belief can require different admissible actions. In that case the belief representation is not sufficient for INSACERMO actionability, and the kernel must retain a richer state/history representation or REFUSE.

## Hypergraph target

On a finite realized belief space, the existing minimal-obstruction hypergraph theorem should apply directly to `GoodBelief`.

Therefore, once belief sufficiency is established, minimal actionability obstructions live on belief states rather than raw histories.

## Guardrails

This target does NOT yet prove:

- Bayesian filtering correctness;
- stochastic transition or observation kernels;
- posterior normalization;
- optimal POMDP control;
- infinite-horizon Bellman equations;
- continuous belief simplices;
- learning an unknown model.

Those are deliberately subsequent tests.

## Falsification boundary

If admissibility cannot be made belief-extensional, belief-state compression is not lossless for actionability. That is a real failure condition, not something to tune away.
